# C++ 指针（& 与 *）

指针允许程序员直接操作内存，可以实现更灵活高效的程序设计。

## 1. 什么是指针

指针是一个变量，其值是另一个变量的内存地址。定义形式：

```cpp
类型名称 *指针变量名;
```

例如声明一个整型指针：

```cpp
int *ptr;
```

此时 `ptr` 是一个指向整数类型的指针变量。

## 2. 指针的基础操作

### 2.1 指针的赋值

把变量的地址赋给指针：

```cpp
int a = 10;
int *ptr = &a;  // 将 a 的地址赋值给 ptr
```

`&` 操作符用来获取变量的地址。

### 2.2 解引用指针

通过指针访问它指向的变量，使用解引用操作符 `*`：

```cpp
int value = *ptr; // 通过 ptr 解引用获取 a 的值
```

`value` 等于 10，因为 `ptr` 指向 `a` 的地址。

### 2.3 & 和 * 的区别

- `&`：取地址操作符，获取变量的内存地址。
- `*`：解引用操作符，访问指针所指向地址的值。

```cpp
int a = 20;
int *ptr = &a; // &a 获取 a 的地址并赋给 ptr
int b = *ptr;  // *ptr 解引用，获取 ptr 指向地址的值
```

例子中 `b` 的值是 20。

## 3. 常见指针应用

### 3.1 动态内存分配

用 `new` 和 `delete` 管理动态内存：

```cpp
int *arr = new int[10]; // 动态分配一个整数数组
for (int i = 0; i < 10; ++i) {
    arr[i] = i; // 赋值
}
delete[] arr; // 释放动态分配的内存
```

### 3.2 函数参数传递（指针）

指针常用于函数参数，允许在函数内修改外部变量的值：

```cpp
void modifyValue(int *ptr) {
    *ptr = 100; // 修改 ptr 指向的变量的值
}

int main() {
    int a = 5;
    modifyValue(&a);
    // 现在 a 的值为 100
}
```

### 3.3 引用参数

通过引用参数，同样可以在函数内直接修改传入的变量，但写起来更简洁：

```cpp
void modifyValue(int &ap) {
    ap = 100; // 修改引用指向的变量
}

int main() {
    int a = 5;
    modifyValue(a); // 通过引用修改 a 的值
    // 此时 a 的值变为 100
}
```

`&` 引用参数避免了传值时的拷贝，提高了性能，还能直接修改原值，尤其在传递大对象时更明显。

### 3.4 指针数组和数组指针

指针数组是存储指针的数组，数组指针是指向数组的指针：

```cpp
int *ptrArray[5]; // 指针数组
int arr[5] = {1, 2, 3, 4, 5};
int (*arrayPtr)[5] = &arr; // 数组指针
```

## 4. 总结

指针在 C++ 中提供了直接操作内存的能力。掌握 `*` 和 `&` 的用法，才能继续深入动态内存管理、函数参数传递以及各种数据结构的实现。
