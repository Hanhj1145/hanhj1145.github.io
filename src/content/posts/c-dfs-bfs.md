# DFS 与 BFS

图论是 OI 中非常重要的领域，而**深度优先搜索（DFS）**和**广度优先搜索（BFS）**是最基础的两种遍历算法。

## 深度优先搜索（DFS）

DFS 会尽可能深地搜索图的分支，当节点 v 的所有边都已被发现时，回溯到发现 v 的边。

### 基本思想

1. 从某个顶点 S 开始，访问 S。
2. 将 S 标记为已访问。
3. 从 S 的未访问邻居中选择一个 V，递归地对 V 执行 DFS。
4. 如果所有邻居都已访问，则回溯到上一个顶点。

DFS 通常用递归实现，回溯过程自然处理。

```cpp
bool vis[MAXN]; // 标记顶点是否已访问

void dfs(int u) {
    vis[u] = true; // 标记当前顶点为已访问
    cout << u << " "; // 访问操作，例如打印顶点

    // 遍历所有与u相邻的顶点v
    for (int v : adj[u]) {
        if (!vis[v]) { // 如果v未被访问过
            dfs(v); // 递归地对v进行DFS
        }
    }
}
```

### 去注释模板

```cpp
bool vis[N];
vector<int>vec[N];
void dfs(int p)
{
	vis[p]=1;
	for(auto it:vec[p])
	{
		if(!vis[it])
		{
			dfs(it);
		}
	}
}
```

### 应用场景

- **连通性判断**：判断图是否连通，求连通分量。
- **拓扑排序**：在有向无环图（DAG）中找出顶点的线性顺序。
- **查找环**：判断图中是否存在环。
- **路径查找**：寻找从起点到终点的路径（不保证最短）。
- **二分图判定**。
- **作为基础**：如求强连通分量的 Tarjan、Kosaraju 算法。

## 广度优先搜索（BFS）

BFS 从起始顶点 S 开始，依次访问距离 S 为 1、2、... 的所有顶点。它使用**队列**实现。

### 基本思想

1. 从某个顶点 S 开始，访问 S，标记已访问并加入队列。
2. 当队列不为空时：
   - 取出队首顶点 U。
   - 遍历 U 的所有未访问邻居 V，标记并加入队列。

```cpp
#include <queue> // 包含队列头文件

bool vis[MAXN]; // 标记顶点是否已访问
int dist[MAXN];    // 存储从起点到各个顶点的距离 (BFS特有应用)

void bfs(int start_node) {
    queue<int> q;

    q.push(start_node);
    vis[start_node] = true;
    dist[start_node] = 0; // 起点距离为0

    while (!q.empty()) {
        int u = q.front(); // 取出队首元素
        q.pop();           // 弹出队首元素

        cout << u << " "; // 访问操作，例如打印顶点

        // 遍历所有与u相邻的顶点v
        for (int v : adj[u]) {
            if (!vis[v]) { // 如果v未被访问过
                vis[v] = true; // 标记为已访问
                dist[v] = dist[u] + 1; // 距离加1
                q.push(v); // 将v加入队列
            }
        }
    }
}
```

### 无注释模板

```cpp
vector<int>vec[N];
bool vis[N];
int dis[N];
void bfs(int start)
{
	queue<int>q;
	q.push(start);
	while(!q.empty())
	{
		int u=q.front();
		q.pop();
		vis[u]=1;
		for(auto it:vec[u])
		{
			if(!vis[it])
			{
				q.push(it);
				dis[it]=dis[u]+1;
			}
		}
	}
}
```

### 应用场景

- **最短路径**：在无权图中，BFS 可以求出从起点到所有其他顶点的最短距离（边数最少），这是它和 DFS 最大的区别。
- **层序遍历**：如树的层序遍历。
- **迷宫问题**：求迷宫中的最短路径。
- **八数码问题**：经典的搜索问题。
- **洪水填充（Flood Fill）**：填充连通区域。

## DFS 与 BFS 的对比

| 特性 | 深度优先搜索（DFS） | 广度优先搜索（BFS） |
|------|--------------------|--------------------|
| 搜索方式 | 深入优先 | 逐层向外扩散 |
| 实现方式 | 递归或栈 | 队列 |
| 空间复杂度 | 递归栈的深度 | O(n+m) |
| 时间复杂度 | O(n) | O(n) |
| 无权图最短路径 | 不能保证 | 能保证 |
| 应用场景 | 连通性、环检测、拓扑排序、路径存在性 | 最短路径（无权图）、层序遍历、迷宫问题 |

如何选：

- 要**最短路径**（无权图）或按"层"遍历，用 BFS。
- 只要**遍历所有可达顶点**、判断**路径是否存在**、需要**回溯**，用 DFS，通常更简洁。

## 小贴士

- **标记访问数组**：无论 DFS 还是 BFS 都需要 `vis` 数组避免重复访问，尤其在环图中防止死循环。
- **初始化**：每次新的图遍历前，初始化 `vis` 和 `dist` 等数组。
- **多源 BFS**：需要多起点同时 BFS 时，把所有起点一次性放入队列即可。
- **路径重建**：需要输出具体路径时，记录每个顶点由哪个前驱访问到。
- **空间优化**：大图优先用邻接表。
